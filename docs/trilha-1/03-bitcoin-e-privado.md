# 3. Bitcoin é privado?

!!! question "A pergunta desta página"
    Muita gente acha que Bitcoin é anônimo. Isso é verdade?

!!! warning "Rascunho em construção"
    Esta página ainda será escrita. Abaixo, o plano.

**Analogia sugerida:** usar um apelido num fórum. Enquanto ninguém liga o apelido a você, parece anônimo. Basta uma ligação para tudo ficar claro.

**Pontos a cobrir**

- Pseudônimo não é o mesmo que anonimato
- Como os históricos de transações públicos podem ser analisados
- Como um endereço pode ser associado a uma pessoa
- Por que isso leva à necessidade de privacidade de verdade
